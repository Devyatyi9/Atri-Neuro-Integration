# Game State Flags (f, tf, sf)

Глобальные объекты-словари для хранения состояния игры.

## f — Temporary Folders (сцена-локальные флаги)

Сбрасываются при загрузке/перезапуске сцены. Используются для временных состояний внутри одной сцены (ветки диалогов, временные переменные).

**Дамп не сохранился** — скорее всего был пуст на момент дампа (сцена не была активна).

```javascript
// Доступ
f.flag_name
f["flag_name"]

// Установка
f.flag_name = value;
```

## tf — Game Temporary Flags (сохраняемые флаги игры)

Сохраняются в файле сейва. Отражают текущее состояние прохождения.

**Ключи из дампа:**
| Ключ | Тип | Описание |
|------|-----|----------|
| `ExecGame` | ? | Игра выполняется |
| `__origDebugLevel` | int | Исходный уровень дебага |
| `bgchange` | bool | Фон менялся |
| `lastSystemVoiceChara` | string | Последний персонаж системного голоса |
| `playmovie` | bool | Видео проигрывается |
| `recollect` | bool | Режим воспоминаний |

**Использование:**
```javascript
tf.ExecGame       // true/false
tf.bgchange       // менялся ли фон
tf.playmovie      // проигрывается ли видео
```

## sf — System Flags (глобальные системные флаги)

Не сбрасываются при загрузке. Хранят достижения, просмотренные CG, прослушанные BGM, настройки.

**Ключи (группы):**
| Группа | Примеры | Описание |
|--------|---------|----------|
| `ac_b*` | `ac_b101クリア` | Прохождение глав (achievement) |
| `bgm_*` | `bgm_BGM01` | Прослушанные треки |
| `cg_*` | `cg_BG001`, `cg_EV001A` | Просмотренные CG/фоны |
| `voice_*` | `voice_●アトリ` | Прослушанные голоса |
| `select_*` | `select_b102_ks_dummyselect10` | Сделанные выборы |
| `autotrail_*` | `autotrail_title_game` | Автотрейл (состояния меню) |
| `trail_*` | `trail_title_game` | Сохранённые трейлы |
| `dispname_*` | `dispname_Атри` | Отображаемые имена |
| `emote_*` | `emote_bustscale` | E-mote настройки |
| `windowOpac` | int | Прозрачность окна |
| `musicvolume` | int | Громкость музыки |

**Использование для Neuro:**
```javascript
// Проверка какие CG уже видели
sf["cg_EV001A"]  // true/false

// Проверка прохождения глав
sf["ac_b101クリア"]  // true/false

// Текущая громкость
sf.musicvolume
sf.windowOpac
```

## Загрузка/Сохранение

```javascript
kag.loadGameSaveSlot(index);  // загрузить слот
kag.saveGameSaveSlot(index);  // сохранить
```

Флаги автоматически сохраняются/загружаются движком.
